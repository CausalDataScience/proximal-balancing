## 0. 이 설계가 Twins와 다른 점

Twins는 결과가 실제이고 proxy가 생성물이다. 여기서는 **proxy가 실제 임상 측정치**다. 중환자실 첫 24시간 혈액검사 10개는 환자의 숨은 생리 상태를 재는 실제 측정이며 측정 오차도 실제다. 생성하는 것은 처치 배정과 심은 효과뿐이다.

| 실제 | 생성 |
|---|---|
| 공변량 54개 | 처치 $A\mid U,X$ |
| 숨은 교란 $U$ = APACHE III 급성 생리 점수(`aps1`), $X$에서 제거 | 심은 효과 $\delta$ |
| proxy 10개, 다섯 임상 블록 (`rhc_data.BLOCKS` 그대로) | |
| 결과 `t3d30`의 실제 변동 | |

근거: 혈액검사 10개가 `aps1`을 $R^2=0.43$으로 맞히고, 다섯 블록이 각각 $R^2$ $0.025$, $0.169$, $0.096$, $0.199$, $0.025$를 담는다. `aps1`은 결과와 상관 $-0.235$, 실제 처치와 $+0.239$다.

## 1. 설계 (고정)

- $U=(\texttt{aps1}-\bar{\cdot})/\mathrm{sd}$. 학습기에 주지 않는다. $X$는 남은 54열.
- $W_1..W_5$는 `rhc_data.BLOCKS`: (`pafi1`,`paco21`), (`ph1`,`hema1`), (`wblc1`,`alb1`), (`bili1`,`crea1`), (`sod1`,`pot1`). 원 측정값 그대로.
- $P(A=1\mid U,X)=0.1+0.8\,\Phi(1.5\,U+w^\top \tilde X)$, $\tilde X$는 표준화한 $X$, $w\sim N(0,0.1^2)$를 seed `98,300,000`으로 한 번 뽑아 모든 replicate에 고정. 계수 $1.5$는 SCM-1의 $U$ 계수, $w$의 분포는 CEVAE 규약.
- $Y=\texttt{t3d30}+\delta\,A$, $\delta=-1.0$. 따라서 모든 단위에서 $Y(1)-Y(0)=\delta$이고 **참 ATE는 정확히 $-1.0$**이다.
- $n=5{,}735$. replicate $r$의 seed는 `98,300,000 + 1000 r`, fold seed는 그 값 $+7$.

## 2. 개발과 확증

- **개발 replicate 0은 이미 열었다.** naive $-3.507$, $X$만 $-1.552$, $X$와 $W$ 전부 $-1.384$, oracle $(X,U)$ $-1.073$. 확증에서 뺀다.
- **확증 replicate 1–10.** 실제 $(X,U,Y_{\text{real}})$은 고정이고 $A$만 새로 뽑으므로, replicate는 배정의 반복이지 자료의 독립 반복이 아니다. 그렇게 보고한다.

## 3. 실행 (고정)

봉인된 `family_v2_probe.run_dataset`를 고치지 않는다. `Level(name="RHC-planted", d_x=54, d_blocks=(2,2,2,2,2), k=2)`. 문턱은 SCM-1의 $1.5\times10^{-3}$, 봉인 규칙과 pooled 규칙을 모두 보고하고 격자 $\{0.5,1,2,4\}\times10^{-3}$로 민감도를 본다. 비교군은 Twins와 같다: naive, $X$만, $X$와 $W$ 전부, oracle $(X,U)$, P2SLS(역할 맞게/바꿔), Park SPC(ATE 변환), CEVAE.

## 4. 이 실험이 시험하지 않는 것

**무효 블록을 심지 않았다.** 다섯 블록 모두 같은 $U$의 실제 측정치이므로 처치 전용 원인에 오염된 블록이 없고, 따라서 심사의 판별력(TPR/FPR)은 여기서 시험되지 않는다. 판별력은 모의실험과 RHC 자체 감사가 맡는다. 여기서 시험하는 것은 **실제 측정 오차를 가진 실제 proxy로 알려진 효과를 되찾는가**뿐이다.

## 5. 보고 항목

replicate 10개 각각의 $\delta=-1.0$ 대비 오차(PROBE 두 규칙, 비교군 전부), 반환 종류와 보류 집합과 $\rho$, 평균 절대오차와 짝지은 한쪽 상한($X$만, raw, CEVAE, oracle 대비). 통과 판정은 하지 않는다.

## 6. 규율

개발 숫자를 본 뒤 $U$, 블록, $\delta$, 계수, seed 중 무엇도 바꾸지 않았다. 결과는 `results/rhc_planted/` write-once. 봉인 파일 해시를 검사로 확인한다.
