# PRD: 원본 이미지에서 직접 배우는 proximal balancing

권고는 Shapes3D부터 직접 CNN 균형학습을 구현하고, 같은 코드를 MNIST에 적용하는 것입니다. 두 실험 모두 목표는 같습니다.

> 각도나 숫자 정답을 맞히는 것이 아니라, 남긴 이미지에서 만든 표현만으로 held-out 이미지의 추가 처치 정보를 없애도록 CNN 전체를 학습한다.

기존 코드에 필요한 부품은 있습니다. 다만 이 방식의 성공과 두 실험의 20 GPU시간 내 완료는 아직 검증되지 않았습니다. 아래 PRD는 그 불확실성을 가장 싼 단계에서 확인하도록 구성했습니다.

## 실행 우선순위(사용자 확정)

이번 승인은 아래 실행 순서를 PRD에 명시하는 문서 수정에 한정하며, 실험 실행을 승인하거나 성공을 확인한 것은 아닙니다.

1. **Shapes3D의 여러 원본 이미지부터 진행합니다.** 기존 이미지 여섯 장·논리 블록 다섯 개·후보 분할 30개를 유지합니다. 각도 라벨로 지도학습한 판독기는 사용하지 않고, CNN 전체를 균형 목적으로 갱신합니다.
2. **한 이미지의 픽셀 블록 실험과 새로운 공간적 DGP 설계는 현재 실행 범위에서 제외합니다.** 이들은 별도 승인 후 다룰 후속 실험입니다.
3. **기존 P0 → 미리 지정한 소수 분할의 CNN 전체 균형학습 검사 → 전체 30분할의 개발 자료 한 개 순서로 진행합니다.** 이 한 번에는 비교군·독립 검사·효과 추정·집계를 모두 포함하여 독립 균형 통계, 효과 오차, 전체 실행시간을 확인합니다. 기존 관문과 예산 조건을 만족할 때만 개발 확대·동결·확증으로 넘어갑니다.
4. **MNIST는 같은 코드로 두 번째에 진행합니다.** 취소하는 것이 아니라, 기존 MNIST P0와 남은 예산 조건을 만족할 때 진행합니다.
5. **총 20 GPU시간과 GPU 작업의 순차 실행 원칙은 그대로 유지합니다.** 여러 이미지가 전체 개발·검증 경로를 재사용하기 쉽다는 판단이지, 한 번의 CNN 계산이나 전체 실행시간이 항상 더 짧다는 보장은 아닙니다.

## 1. 무엇을 확인하는 실험인가

확인할 질문은 세 가지입니다.

1. 균형 목적이 CNN의 실제 가중치를 움직여 독립 자료에서도 잔여 불균형을 줄이는가?
2. 그렇게 배운 표현으로 인과효과를 정확하게 추정하는가?
3. 균형학습을 하지 않은 동일한 출발점과, 전체 이미지를 사용하는 강한 CNN 조정보다 나은가?

이 셋을 분리해서 판단합니다. 목적값이 작아졌다는 이유만으로 인과효과 추정도 좋아졌다고 판정하지 않습니다.

### 이번 실험에서 하지 않을 것

- 각도·숫자 라벨을 CNN 학습 목표로 사용하지 않습니다.
- 각도를 먼저 복원하고, 복원한 숫자로만 balancing하지 않습니다.
- CNN을 고정하고 마지막 선형층만 학습하지 않습니다.
- raw CNN이 일부러 틀리도록 학습량을 줄이지 않습니다.
- 이미지 결과를 곧바로 finite-sample theorem의 검증이라고 부르지 않습니다.
- 기존 SCM-1–3과 봉인된 결과는 변경하지 않습니다.

원고와의 관계: 원고 Section 4의 Brier-risk 목적을 신경망으로 최적화하는 실험입니다. 다만 신경망의 전역 최적해, 모집단의 정확한 균형, 정리의 모든 가정까지 인증하는 실험은 아닙니다. 원고도 critic 근사오차와 표현 최적화오차를 별도로 둡니다. [원고 Section 4](/Users/yonghanjung/paios/research/papers/single_proxy_balancing/manuscript/main/4.tex:88)

## 2. 자료 생성: 기존 SCM을 유지하고, 관측 방식만 이미지로 바꾼다

여기서 관측자료는 다음 네 종류뿐입니다.

- $X$: 관측 공변량.
- $W$: 이미지로 기록된 대리변수.
- $A$: 처치 여부.
- $Y$: 결과.

숨은 변수와 이미지의 정답 속성은 생성기와 사후 평가기만 사용합니다. 학습기에 별도 숫자로 넘기지 않습니다.

### 공통 구조

검증된 SCM-1의 생성식·계수·관측 좌표 회전을 그대로 재사용합니다. 참 평균 처치효과는 $\tau=1$입니다.

기존 SCM-1에는 관측 대리변수 좌표가 여섯 개 있습니다. 새 실험은 각 좌표를 원본 이미지 한 장으로 기록합니다.

| 항목 | 두 실험의 공통 사양 |
|---|---|
| 관측 이미지 | 한 관측대상당 여섯 장 |
| 논리 블록 | 다섯 개 |
| 블록 구성 | $W_1,\ldots,W_4$는 각각 이미지 한 장, $W_5$는 이미지 두 장 |
| 후보 분할 | 다섯 블록의 공집합·전체집합을 제외한 30개 전부 |
| 블록 역할 | 학습기에 제공하지 않음 |
| 픽셀 | 벤치마크 원본 유지. 표식·국소 변형 없음 |

이미지 여섯 장과 블록 다섯 개는 다릅니다. 다섯째 블록의 두 이미지는 항상 함께 남기거나 함께 제외합니다. 어떤 블록이 타당한지는 알고리즘이 미리 받지 않습니다.

이 실험은 “진짜 영상에서 자연적으로 발생한 인과관계”가 아니라, 알려진 인과구조의 측정값을 실제 벤치마크 이미지로 관측하는 통제된 시뮬레이션입니다.

### Shapes3D

- 관측 좌표를 기존 SCM-4와 동일하게 15단계로 이산화합니다.
- 해당 단계의 orientation을 가진 원본 이미지를 선택합니다.
- 색상·크기·형태 등 나머지 요인은 정해진 은행에서 무작위로 선택합니다.
- CNN은 orientation 정답을 받지 않습니다.
- 기존 각도 지도학습 판독기의 가중치는 주 실험에 사용하지 않습니다.

우선하는 이유: 이미지 은행과 생성 경로가 준비되어 있고, 정확한 단계 값을 사용한 기존 절차가 작동했다는 대조 결과가 있습니다. 따라서 새로 검증할 핵심을 CNN 균형학습에 집중할 수 있습니다.

### MNIST

- 같은 관측 좌표를 10단계로 이산화합니다.
- 각 단계에 숫자 $0,\ldots,9$를 대응시키고, 해당 숫자의 원본 이미지를 선택합니다.
- 좌표 하나당 숫자 이미지 한 장입니다.
- 숫자 분류 정답은 학습기에 주지 않습니다.

이전의 “두 자리 숫자로 하나의 값을 표현”하는 방식은 사용하지 않습니다. 십의 자리 오독이 큰 수치 오차를 만드는 별도의 문제가 있었기 때문입니다.

다만 10단계 이산화가 충분한지는 아직 확인되지 않았습니다. MNIST는 이 부분부터 CPU 대조로 검사합니다.

### 중요한 이론적 제한

연속 측정값을 10개 또는 15개 범주로 바꾸면 정보가 줄어듭니다. 따라서 기존 SCM의 결과 관련 완전성, 즉 proxy가 인과효과 식별에 필요한 숨은 정보를 충분히 구별한다는 조건이 자동으로 유지되지는 않습니다.

그러므로:

> 수치형 대조가 잘 작동하는지 먼저 확인하고, 이미지 실험에서는 직접 균형학습의 경험적 성능을 보고한다.

가 기본 원칙입니다. 작은 실험의 성공을 완전성의 증명으로 대체하지 않습니다.

## 3. CNN이 정확히 무엇을 배우는가

검사 대상으로 제외한 블록 집합을 $S$, 남긴 블록을 $W_{-S}$라고 하겠습니다.

CNN은 남긴 이미지와 $X$를 받아 다음 표현을 만듭니다.

$$
Z_{S,\theta}
=
\bigl(X,h_{S,\theta}(W_{-S},X)\bigr).
$$

$\theta$는 CNN 몸통과 마지막 표현층의 모든 가중치입니다. 첫 버전에서 $h_{S,\theta}$의 출력은 2차원으로 고정합니다.

### 사용자가 확인 요청한 모집단 학습 목적

표현을 $Z=\phi_\theta(X,W_{-S})$라고 쓰면, 학습하려는 모집단 목적은 다음과 같습니다.

$$
\min_\theta D_{\mathrm{res},S}^{2}(\phi_\theta),
\qquad
D_{\mathrm{res},S}^{2}(\phi_\theta)
=
\mathbb E\!\left[
\left\{
P(A=1\mid X,W_S,Z)-P(A=1\mid Z)
\right\}^{2}
\right].
$$

목표값은 $0$입니다. CNN 몸통과 표현층 전체를 이 목적의 경험적 Brier 근사로 갱신합니다. 다만 모든 분할 $S$에서 $0$이 가능하거나 실제 학습으로 달성된다고 보장하지는 않습니다.

### 두 처치 예측기

Critic은 여기서는 처치 $A$를 예측하는 신경망입니다.

| 예측기 | 입력 | 질문 |
|---|---|---|
| 기본 critic $q_0$ | $Z_{S,\theta}$ | 학습된 표현만으로 처치를 얼마나 예측하는가? |
| 증강 critic $q_1$ | $Z_{S,\theta},X,W_S$ | 제외한 이미지까지 보면 처치를 더 잘 예측하는가? |

예측의 제곱오차를 Brier loss라고 합니다.

$$
\widehat R_b
=
\frac{1}{n}\sum_i\{A_i-q_b(\text{입력}_i)\}^2.
$$

CNN의 학습 목표는 원고의 clipped Brier gap입니다.

$$
\widehat G_S(\theta)
=
\max\{\widehat R_0-\widehat R_1,0\}.
$$

학습 목표는 이것 하나입니다. CNN을 균형학습하는 동안 숫자 분류, 각도 회귀, 이미지 재구성, 결과 $Y$ 예측을 추가 목적함수로 섞지 않습니다.

### 최소 신경망 구성

- 이미지별 작은 CNN.
- 남긴 이미지의 특징을 결합하는 표현층.
- 기본 critic은 작은 다층 신경망.
- 증강 critic은 held-out 원본 픽셀 전체를 읽는 별도 CNN을 포함.
- 표현 CNN과 critic CNN은 가중치를 공유하지 않음.
- 증강 critic은 held-out branch를 0으로 두면 기본 critic을 그대로 재현할 수 있도록 구성.

첫 버전은 CNN으로 갑니다. ViT 비교는 이 핵심 질문을 답하는 데 필수적이지 않으므로 제외합니다.

## 4. 실제 학습 순서

### 초기화

이미지 라벨을 쓰지 않는 재구성 사전학습은 초기 가중치 준비용으로만 허용합니다.

- Shapes3D: 기존 라벨 없는 autoencoder 가중치를 초기값으로 재사용할 수 있습니다.
- MNIST: 원본 학습 이미지에서 짧은 고정 일정으로 같은 목적의 초기값을 준비합니다.
- 이후 CNN 몸통을 모두 풀고 balancing으로 갱신합니다.

기존 Shapes3D autoencoder가 각도를 선형으로 읽는 검사에서 실패했다는 기록은 그대로 남깁니다. 새 실험은 그것을 “통과”로 바꾸는 것이 아니라, 고정된 특징을 쓰지 않고 전체 CNN을 다시 학습하는 별도 실험입니다.

### 분할 하나의 학습

1. CNN을 고정하고 두 critic을 처치 $A$에 적합합니다.
2. Critic 가중치를 고정합니다.
3. 전체 학습자료의 Brier gap을 계산합니다.
4. 그 gap의 기울기를 CNN 몸통과 표현층까지 역전파합니다.
5. 두 critic을 다시 적합합니다.
6. 이를 반복합니다.

초기 개발 설정은 다음으로 제한합니다.

| 항목 | 출발 설정 |
|---|---:|
| critic 초기 적합 | 100 minibatch 갱신 |
| 교대 반복 | 20회 |
| 반복마다 critic 적합 | 25 minibatch 갱신 |
| 반복마다 CNN 갱신 | 전체 학습자료에 대한 기울기 누적 후 1회 |
| checkpoint | 초기값, 반복 5·10·20회 |
| optimizer | Adam, critic $10^{-3}$, CNN $10^{-4}$ |
| batch size | 256, 메모리 때문에 줄이면 기울기 누적으로 보정 |

이는 검증된 충분 학습량이 아니라 출발 설정입니다. 실제 학습곡선으로 부족 여부를 판단합니다.

### 구현에서 반드시 지킬 차이

다음 둘은 다른 목적함수입니다.

$$
\max\{\text{전체 자료의 평균 gap},0\}
\neq
\text{minibatch별 }\max\{\text{gap},0\}\text{의 평균}.
$$

원고에 맞추기 위해 전체 자료의 signed gap과 기울기를 누적한 뒤, 전체 gap이 양수일 때만 CNN을 갱신합니다. 전체 gap이 음수이면 음수를 더 크게 만들도록 학습하지 않습니다.

Checkpoint도 더 큰 음수를 보상하지 않습니다. clipped 목적이 동점이면 미리 정한 규칙으로 먼저 나온 checkpoint를 선택합니다.

초기 gap이 0이라는 이유만으로 성공 또는 실패로 판정하지 않습니다. 실제 균형일 수도 있고 critic이 정보를 못 찾는 것일 수도 있으므로 별도 검사가 필요합니다.

## 5. 자료를 어떻게 나누는가

첫 버전은 네 번 회전하지 않고 한 번의 독립 분할로 갑니다. 분할별 CNN 학습은 유지하면서 계산량을 줄이기 위한 선택입니다.

자료 하나당 관측대상 30,000명을 제안합니다.

| 용도 | 행 수 | 사용하는 일 |
|---|---:|---|
| 표현 학습 | 4,800 | CNN과 critic 교대학습 |
| 학습 중 선택 | 1,200 | checkpoint 선택 |
| 독립 균형 검사 | 6,000 | 고정 CNN에 새로운 critic을 적합하고 평가 |
| 최종 추정용 모형 학습 | 6,000 | 처치확률·결과 평균 학습 |
| 최종 효과 평가 | 12,000 | 효과 추정값 계산 |
| 합계 | **30,000** | |

독립 균형 검사 6,000행은 반씩 나누어, 한쪽에서 critic을 적합하고 다른 쪽에서 평가한 뒤 역할을 바꿉니다.

균형 검사나 최종 평가를 본 뒤 CNN checkpoint를 다시 고르지 않습니다.

### 이미지 은행도 분리한다

- 초기화에 사용한 이미지와 인과자료 이미지 은행을 분리합니다.
- 이미지 정답 속성·원본 식별자는 생성·검증용 metadata에만 둡니다.
- 같은 고정 이미지 은행에서 여러 인과자료를 생성한다면, 결과는 그 은행을 조건으로 한 새 관측자료에 대한 성능입니다. 매번 새로운 이미지에 일반화했다고 표현하지 않습니다.

## 6. 검사와 Algorithm 1 집계

30개 분할을 모두 실행합니다. 정답 held-out 분할을 골라 주지 않습니다.

### 균형 검사

기존 SCM-1–3의 독립 검사를 출발점으로 사용합니다.

- 새로운 critic으로 계산한 signed Brier gap.
- 그 gap의 표준오차.
- 30개 후보를 고려한 보수적인 상한.
- overlap 확인.

개발 출발 문턱은 기존 값 $t=1.5\times10^{-3}$입니다. 새 CNN에서도 이 문턱이 충분하다고 가정하지는 않습니다.

문턱이 작동하지 않으면 확증에 들어가기 전에 이유를 보고합니다. 성공률을 높이려고 확증자료에서 문턱을 바꾸지 않습니다. 개발 단계 수정도 변경 이유와 새 버전을 남깁니다.

### 집계

통과 후보마다 효과를 추정하고, 다음을 그대로 수행합니다.

1. 두 추정값의 거리가 $2\rho$ 이하이면 연결.
2. 연결된 후보들의 집단을 계산.
3. 유일하게 가장 큰 집단의 중앙값 반환.
4. 가장 큰 집단이 동점이면 무반환 기록.

$\rho$는 기존의 공동 점수 변동을 이용하는 경험적 규칙을 재사용합니다. 이 반경을 원고의 이론적 상계와 같은 것으로 부르지 않습니다.

모든 후보가 한 집단으로 연결되면 그것도 그대로 보고합니다. 집계 단계가 오답을 분리했다고 주장하려면 실제 분리 기록이 있어야 합니다.

## 7. 비교군: 무엇 때문에 좋아졌는지 구별한다

최소 비교군은 아래 다섯 가지입니다.

| 방법 | 확인하는 질문 |
|---|---|
| $X$만 조정 | 이미지 정보 없이 얼마나 틀리는가? |
| 전체 이미지 raw CNN 조정 | balancing 없이도 충분한가? |
| 동일 초기값, balancing 전 표현 | 균형학습 자체가 개선했는가? |
| 직접 CNN balancing | 제안 방법 |
| oracle | 숨은 교란변수를 관측했다면 어느 정도 정확한가? |

Oracle은 평가용 비교군에만 숨은 변수를 제공합니다.

Raw CNN은 같은 라벨 없는 초기값과 같은 관측자료를 사용하되, 전체 이미지를 이용해 처치와 결과를 예측하도록 충분히 학습합니다. 약한 비교군으로 만들지 않습니다.

Balancing 전후 비교에서는:

- 같은 초기 CNN.
- 같은 자료 분할.
- 같은 최종 추정 모형 구조와 seed.
- 같은 검사·집계 절차.

를 사용합니다. 이 대조의 추가 계산도 예산에 포함합니다.

Raw CNN이 더 좋으면 그것이 결과입니다. DGP나 비교군을 사후 수정하여 PROBE 우위를 만들지 않습니다.

## 8. 실행 순서와 중단 기준

### P0. CPU에서 이미지 이전의 대조부터 확인

이미지 대신 정확한 15단계·10단계 값을 넣어 새 표본 분할에서 실행합니다.

목적은 “이미지를 완벽하게 읽어도 실패하는 문제”에 GPU를 쓰지 않는 것입니다.

개발 자료 세 개에서 다음을 확인합니다.

- 무조정 부호 역전.
- $X$만 조정했을 때의 잔여 오차.
- 전체 측정값 조정과 oracle의 성능.
- 기존 숫자형 balancing의 반환과 정확도.
- 10단계 이산화가 결과를 크게 망가뜨리는지.

최소 진입 기준은 세 자료 모두 정상 반환하고, 각 절대오차가 0.10 이하인 것입니다. 통과는 이후 이미지 학습의 성공을 보장하지 않습니다.

MNIST가 여기서 실패하면 MNIST CNN은 학습하지 않습니다. 먼저 “10단계 관측계의 문제”로 분리합니다.

### P1. Shapes3D에서 critic과 역전파 확인

미리 지정한 소수 분할에서 다음만 검사합니다.

- 알려진 불균형 대조 표현에서 critic이 추가 처치 정보를 검출하는가?
- 처치를 무작위로 섞은 대조에서는 거짓 신호가 과도하지 않은가?
- 양의 gap에서 CNN 몸통까지 기울기가 전달되는가?
- 가중치가 실제로 바뀌는가?
- 학습 gap만 줄고 독립 gap은 늘지 않는가?

기울기가 전달되지 않거나 critic이 양의 대조를 읽지 못하면 전체 실행에 들어가지 않습니다.

### P2. 전체 30분할, 개발 자료 한 개

여기서 처음으로 전체 실행시간을 잽니다.

- CNN 학습.
- 독립 검사.
- balancing 전후 대조.
- raw CNN.
- 최종 효과 추정.
- 집계.

이 전체 시간을 봐야 20 GPU시간 안에 가능한지 판단할 수 있습니다.

### P3. 개발 세 개씩

Shapes3D를 먼저 세 개까지 진행합니다. 그동안 MNIST는 CPU 자료 준비만 병행합니다.

Shapes3D에서 전체 절차가 작동하면 MNIST도 같은 알고리즘으로 진행합니다. 두 benchmark에 별도의 복잡한 학습기를 개발하지 않습니다.

개발에서 명백한 critic·최적화 문제가 발견되면 한 차례의 좁은 수정까지만 계획합니다. 반복적인 설정 탐색으로 예산을 소모하지 않습니다.

### P4. 규약 동결과 새 자료 확증

개발을 마치면 다음을 고정합니다.

- 코드·초기 가중치 해시.
- 자료 생성과 은행 분할.
- 학습량과 checkpoint 규칙.
- 검사 문턱과 반경 계산법.
- 비교군.
- 확증 seed와 판정 기준.

그 뒤 benchmark마다 새 자료 20개를 실행합니다. 실패 seed를 빼거나 교체하지 않습니다.

## 9. PASS를 어떻게 나누는가

| 판정 | 조건 |
|---|---|
| 구현 PASS | 픽셀 입력, 라벨 누출 없음, CNN 전체 갱신, 독립 검사, 30분할 및 실패 기록 완결 |
| 균형학습의 효과 | 동일 초기값 대비 독립 균형 통계가 개선되는지 보고 |
| 인과 성능 PASS | 평균 절대오차 $\le0.05$, 오차 p90 $\le0.10$ |
| Oracle 근접 PASS | oracle 대비 초과 절대오차의 짝지은 95% 신뢰상한 $\le0.05$ |
| 비교 우위 PASS | raw CNN 및 balancing 전 대비 절대오차 차이의 짝지은 95% 신뢰상한 $<0$ |

평가 단위는 독립 자료 20개입니다. 한 자료의 30개 분할을 독립 반복 30개로 세지 않습니다.

무반환과 동점은 별도로 공개하고 실패로 집계합니다. 반환한 자료만 골라 전체 성능 PASS를 주지 않습니다. 첫 확증에서는 해석을 단순하게 하기 위해 20개 모두 반환하는 것을 완전한 성공 기준으로 권합니다.

각도 복원율·숫자 분류 정확도·개별 계수 복원율은 주 관문이 아닙니다. 이번에 필요한 것은 표현이 균형과 효과 추정에 유용한가입니다.

## 10. 계산 예산: 20 GPU시간

### 확인된 것과 아직 모르는 것

기존 코드에 CNN 교대학습 부품은 있습니다. 하지만 기존 SCM-4의 빠른 실행시간은 이미 숫자로 읽은 여섯 좌표를 처리한 시간이므로 이번 비용으로 사용할 수 없습니다.

한 번 분할 방식으로도 두 benchmark를 20회씩 확증하면:

$$
30\text{ 분할}\times20\text{ 자료}\times2\text{ benchmark}
=
1{,}200\text{ 분할별 CNN 학습}
$$

이 필요합니다. 네 번 회전하면 4,800개입니다. 따라서 첫 버전에서 회전을 제외합니다.

### 예산 배분안

아래는 실행시간 예측이 아니라 사용 상한 배분입니다.

| 단계 | GPU시간 상한 |
|---|---:|
| 초기값 준비 | 1.0시간 |
| critic·역전파 smoke 및 시간 측정 | 1.0시간 |
| Shapes3D 개발 | 2.0시간 |
| MNIST 개발 | 1.5시간 |
| Shapes3D 확증 20개 | 7.0시간 |
| MNIST 확증 20개 | 5.0시간 |
| 예비분 | 2.5시간 |
| 합계 | **20.0시간** |

이 배분이 가능하려면 비교군까지 포함한 자료 하나의 실행시간이 대략:

- Shapes3D: 21분 이하.
- MNIST: 15분 이하.

여야 합니다. 아직 이 속도를 확인하지 못했습니다.

### 예산이 안 맞으면

- GPU 작업은 한 번에 하나씩 실행합니다.
- 전체 실행시간의 보수적인 예상치가 남은 예산을 넘으면 확증 시작 전에 멈춥니다.
- 우선순위는 Shapes3D 확증 완료 → MNIST 확증입니다.
- 분할 수·반복 수·비교군을 몰래 줄이지 않습니다.
- 두 실험 모두 무리하게 시작해 둘 다 미완료로 남기는 것보다, 하나를 제대로 완료합니다.

두 실험 확증까지의 일정은 첫 전체 실행을 재기 전에는 약속하지 않겠습니다. CPU 준비와 보고서 작성은 GPU 사용시간과 별개입니다.

## 11. 구현자가 반드시 넣을 검사

기존 [CNN 균형학습 코드](/Users/yonghanjung/paios/research/papers/single_proxy_balancing/code/multi_image_probe.py)는 출발점으로 활용하되 그대로 호출하지 않습니다.

최소 검사는 다음과 같습니다.

1. 입력 검사: 학습기는 $X$, 이미지, $A$, $Y$ 외의 정답 정보를 받지 않음.
2. 마스크 검사: 표현 CNN에 held-out 픽셀이 들어가지 않음.
3. 블록 검사: 다섯째 블록의 두 이미지는 함께 이동.
4. 기울기 검사: 양의 gap에서 CNN 몸통까지 실제 갱신.
5. 목적 검사: 전체 평균 후 clipping과 작은 자료의 직접 계산 일치.
6. 포함관계 검사: held-out branch를 0으로 두면 기본 critic을 그대로 재현.
7. 독립성 검사: 학습·선택·검사·추정·평가 행 교집합이 0.
8. 완결 검사: NaN, timeout, 누락, 동점, 무반환을 조용히 제외하지 않음.
9. 재현 검사: 코드·모델·자료 분할 해시 일치.
10. 메모리 검사: 원본 은행은 uint8로 두고 batch만 GPU에 올림.

기존 코드의 후보 추정 실패를 조용히 제외할 수 있는 경로와, 네 이미지·네 블록 하드코딩은 새 실행 경로에서 반드시 제거해야 합니다.
