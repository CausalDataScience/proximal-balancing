\section{Problem Setting}
\label{sec:setup}

\subsection{Preliminaries}
\label{sec:preliminaries}

\paragraph{Structural causal models.}
A structural causal model (SCM) consists of endogenous variables, exogenous disturbances, and structural assignments. Writing the endogenous variables as $S_1,\ldots,S_d$, an acyclic SCM has equations
\begin{align}
S_k=f_k(\operatorname{pa}_k,E_k),
\qquad k=1,\ldots,d,
\end{align}
where $\operatorname{pa}_k$ contains the direct causes of $S_k$ and $E_k$ is an exogenous disturbance. The intervention $\operatorname{do}(A=a)$ replaces the structural equation for $A$ by the constant $a$ while leaving the other equations unchanged. The resulting outcome is the potential outcome $Y(a)$. An average causal effect is \emph{identified} when its value is uniquely determined by the observed-data distribution for every SCM in the stated model class \citep{pearl2009causality}.

\paragraph{Proximal causal inference.}
Ordinary adjustment seeks observed covariates that block all noncausal paths from treatment to outcome. Proximal causal inference instead allows an unobserved confounder and uses proxy measurements of it. Standard proximal formulations assign two different proxy roles and posit a bridge equation whose solution translates an observable conditional moment into the target causal functional \citep{miao2018proxy,tchetgen2024ProximalCausalInference}. Their completeness condition requires the relevant conditional-expectation operator to be injective, so that no nonzero latent function is invisible to all proxy conditional moments. This condition does not follow from the mere existence of a correlated proxy. PROBE instead uses outcome-relevant completeness to interpret exact balance measured through a held-out proxy block and a quantitative stability condition when balance is only approximate.

\subsection{Problem Setting}
\label{sec:problem-setting}

We observe independent copies
\begin{align}
O_i=(X_i,W_i,A_i,Y_i),
\qquad i=1,\ldots,n,
\end{align}
where $X$ is a possibly high-dimensional vector of observed pretreatment covariates, $A\in\{0,1\}$ is treatment, and $Y$ is the observed outcome. The observed pretreatment measurement $W$ is divided into prespecified blocks,
\begin{align}
W=(W_1,\ldots,W_J).
\end{align}
Each block may be scalar or vector-valued. A block can represent one repeated measurement, sensor channel, laboratory panel, or prespecified region of a larger measurement. We call $W$ a candidate proxy because some or all blocks may contain information about an unobserved pretreatment variable $U$ that affects treatment selection and the outcome.

Fix one block index $j\in\{1,\ldots,J\}$ before analyzing the data. We call $W_j$ the \emph{held-out proxy block} and write
\begin{align}
W_{-j}
\triangleq
(W_1,\ldots,W_{j-1},W_{j+1},\ldots,W_J)
\end{align}
for all remaining proxy blocks. The measured input available for constructing an adjustment representation is
\begin{align}
V_j\triangleq(X,W_{-j}).
\label{eq:representation-input}
\end{align}
The representation itself is introduced only in Section~\ref{sec:identification}.

For each $a\in\{0,1\}$, let $Y(a)$ denote the outcome that would be observed if treatment were set to $a$. The target is the population average treatment effect
\begin{align}
\tau\triangleq\mathbb E\{Y(1)-Y(0)\}.
\end{align}
We allow $U$ to remain associated with treatment after conditioning on all observed pretreatment measurements. The research question is whether the prespecified block structure can support a learned adjustment representation that identifies $\tau$ under exact PROBE balance and controls residual hidden-confounding bias when balance is approximate. The representation and the assumptions that give its balance a causal meaning are introduced next.
